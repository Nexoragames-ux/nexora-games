NEXORA GAMES — STARTER WEBSITE

What's included:
- Responsive gaming portal homepage
- Search and category filters
- 10 small browser mini-games that run locally in the browser
- No accounts, database, payment system, or advertising configured yet

HOW TO PREVIEW:
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For development, use VS Code and its Live Server extension (optional).

HOW TO PUBLISH FOR FREE:
1. Create a GitHub account.
2. Create a new public repository named nexora-games.
3. Upload index.html, style.css, and script.js.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will provide a public website address.

IMPORTANT:
- Nexora Games is a working project name, not a checked trademark or domain.
- This is the first front-end version. It does not yet have user accounts, cloud saves,
  online multiplayer, payments, premium access, or ad integration.
- Before monetizing, add original/licensed games, privacy and terms pages, and follow
  the applicable platform/payment/ad network policies.
- Free hosting plans have usage limits and terms that can change.
